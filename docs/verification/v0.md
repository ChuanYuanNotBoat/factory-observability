# V0 验证记录

验证日期：2026-10-30。目标：Windows、JDK 21、Minecraft 1.21.1、NeoForge 21.1.248、官方 Mojang mappings。

## 自动验证

`gradlew.bat build :test-fixtures:run` 通过。当前共 34 项 JUnit 测试，覆盖：

- 资源变体、单位、有限数值、coverage/confidence 分离及未知 availability。
- 世界/维度/主体隔离，半开查询区间、乱序样本排序、内存容量上限。
- 工厂图引用、重复身份、跨世界节点和 Stage 循环验证。
- 队列处理预算、溢出计数、故障订阅者隔离和提供者启动失败后的清理。
- 菜单合并、资源替换归零、读取失败/关闭后的保留值、空库存心跳及可见性区间。
- 用户声明边、节点淘汰、掉落物删失与本地加盐世界身份。

Core JDK-only 隔离检查、安装包共享类与元数据检查均通过。

## 真实客户端验证

`gradlew.bat :platform-neoforge:verifySmokeClient` 在专用 `run-smoke/` 目录运行已打包 JAR 与独立测试 addon。测试不修改已有游戏实例和存档。生产 Mod 类的来源被检查为安装包 JAR，测试 addon 不进入该安装包。

验证内容：

1. 创建新的平坦测试世界，真实服务器菜单向客户端同步测试箱子。
2. 32 + 16 个铁锭合并为 48；4 个带名称组件的铁锭保持独立。
3. 玩家背包中 64 个钻石不进入容器观测。
4. 将普通铁锭替换为金锭，确认普通铁锭指标出现显式零值。
5. 关闭菜单和移除掉落物，确认最后数量保留且可见性中断，未编造拾取或销毁事件。
6. 实际点击容器入口，验证关闭菜单前采集；完成搜索清除、改名、O 键输入保护、去向选择/取消/确认、删除与撤销。
7. 在中英文、GUI 缩放 2/3 下检查图标库存和去向备注，并检查首次使用、帮助、目的地选择及容器入口，共十二张截图。
8. 观测管线无错误和丢弃，测试正常保存并退出。

截图由验证任务写入 `platform-neoforge/run-smoke/screenshots/factoryobs-*.png`，不提交生成的游戏目录。重新运行任务可生成同名文件；测试世界使用唯一名称。

## 已知边界

- 本版提供容器与物品记录、可选去向备注等辅助功能。只有客户端已经同步的数据可观察。
- 工厂分组按当前世界会话自动生成，容器以菜单会话作为节点，不自动识别物理容器位置；自定义范围/Stage 编辑未实现。
- 去向备注由玩家手动标记，不代表自动搬运、吞吐或因果关系已被测量。
- 历史、连接和分组只在内存中；没有 SQLite、持久化迁移、速率推断或导出。
- Fabric、原生工业 Mod 适配器和 LItemFinder 提供者尚未接入。LItemFinder 当前未暴露本项目所需的稳定 availability API，不读取它的内部索引。
- 实体观测有数量上限；超过预算的加入事件计为跳过，不会在有空位时自动回补所有先前跳过的实体。重新进入跟踪范围可再次被发现。
- 单人集成服务器验证不能代替纯原版远程服务器握手、第三方复杂菜单、切换维度和高负载长时间运行的专项测试。
